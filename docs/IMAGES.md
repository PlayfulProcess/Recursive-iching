# Images — the registry

Every picture this repo points at, what it is, and why we are allowed to use it.

The rule, mirroring the sibling [Recursive Astrology](https://github.com/PlayfulProcess/Recursive-astrology)
repo and this repo's text policy: **public domain only, and verified — the file page
opened and the licence tag read, not guessed.** CC-BY and CC-BY-SA are *not* public
domain; several otherwise-perfect candidates were rejected on exactly that ground and are
listed below so nobody re-proposes them.

The machine-readable copy of all of this lives inside each grammar as
`_image_provenance` (shape documented in [`GRAMMAR_FORMAT.md`](../GRAMMAR_FORMAT.md#image-provenance--a-recursive-i-ching-extension));
`python check.py` fails if an image has no provenance entry, if an entry is missing a
field, or if two grammars share a cover.

All URLs below were fetched on **2026-07-26**: each file page returned HTTP 200, and each
`Special:FilePath` URL returned HTTP 200 with an `image/*` content type.

## Still without an image (honest gaps)

- No per-item images anywhere. The 64 hexagrams are drawn as Unicode glyphs and live
  line-diagrams by the viewers themselves, which is more accurate than any single scan
  and does not repeat one picture 64 times. Per-item pictures would only be worth adding
  if each hexagram got a *different*, verified, historically-specific plate — e.g. from a
  fully-digitised public-domain edition. Not attempted here.
- `public/viewers/books.html` and `public/viewers/caster.html` carry no images. Nothing
  verified was apt enough to justify one; left alone deliberately.
- The Legge (1899) and Wilhelm title pages named in the family plan were **not found** as
  verifiable standalone Commons files during this pass — only whole-volume DjVu/PDF scans
  turned up, which are not usable as a hotlinked cover. Left as a gap rather than
  substituting something near-enough.
